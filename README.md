# Алгоритмы кластеризации и понижения размерности

Лабораторные работы и практики по курсу «Алгоритмы кластеризации и понижения размерности».
Все блокноты запускались в Google Colab (Python 3).

## Содержание

| папка | что внутри |
|---|---|
| `lab1/` | ЛР1: `practice1.ipynb` - библиотеки, первичный анализ, визуализация, нормализация (Iris, Wine); `lab1_clustering.ipynb` - доработка библиотеки `multidim_visualization.py`, кластеризация и 2D/3D визуализация (Wine, проверка на Breast Cancer) |
| `lab2_svd/` | ЛР2: SVD - подпространства, теорема Эккарта-Янга, полярное разложение, PCA через SVD и собственные векторы, псевдообратная матрица |
| `lab3_manifold/` | ЛР3: manifold learning - MDS, LLE, Isomap на разных поверхностях, digits, классификация после понижения размерности |
| `practice7/` | Практика 7: t-SNE, UMAP, TriMAP, PaCMAP, PHATE на Iris и Wine, устойчивость к параметрам, предобработка |
| `practice8/` | Практика 8: понижение размерности + кластеризация (digits, Iris, Wine), метрики, устойчивость, комплексная метрика |
| `final_project/` | Итоговая работа: кластеризация футболистов топ-5 лиг (сезон 2022/23) по стилю игры |

## Данные

- `lab1/breast_cancer.csv` - Breast Cancer Wisconsin (для проверки библиотеки на другом датасете через CSV).
- `lab3_manifold/hello.png` - картинка с надписью для построения поверхностей.
- `practice7/my_data.csv` - собственный датасет (Wine), если файла нет - блокнот создаёт его сам.
- `final_project/data/2022-2023 Football Player Stats.csv` - [2022-2023 Football Player Stats](https://www.kaggle.com/datasets/vivovinco/20222023-football-player-stats) с Kaggle (FBref). В блокноте датасет скачивается через `kagglehub`, копия лежит в `data/`.
- Iris, Wine, digits, china.jpg берутся из `sklearn.datasets`.

## Запуск

```
pip install -r requirements.txt
```

В Colab нужные пакеты ставятся первой ячейкой каждого блокнота. `trimap` при установке собирает `annoy`, это занимает около минуты.
Числа в выводах могут немного отличаться от моих из-за версий библиотек и многопоточности UMAP/TriMAP, выводы от этого не меняются.
